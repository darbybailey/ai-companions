# AI Companions

**Modular persona-based journaling and interaction system with privacy-first design**


## Overview
AI Companions provides a secure, expressive platform for interacting with personalized AI personas, journaling via voice, and exploring emotional patterns over time.


## Features
- Persona system with modular skins
- Voice journaling with sentiment tagging
- Privacy-preserving storage
- FastAPI backend and React UI


## Technologies
- Python 3.10+
- FastAPI
- React/TypeScript
- NLP/SpaCy
- Docker/Kubernetes


## Getting Started
1. Clone the repo
2. Setup `.env` file
3. Run `docker-compose up`
4. Access UI on `localhost:3000`, API on `localhost:8000/docs`
